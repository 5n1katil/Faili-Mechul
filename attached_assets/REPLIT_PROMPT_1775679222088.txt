-----------------------------------------------------------------------
PROJE NEDİR?
-----------------------------------------------------------------------

"Faili Meçhul" adlı bir Türkçe mobil dedektif bulmaca oyunu
geliştiriyorum. Oyuncu; şüpheli, silah ve mekan seçerek cinayeti
çözmek zorunda. Murdle oyunundan ilham alındı, mobil öncelikli.

Elimde 25 premium bulmacadan oluşan bir JSON veritabanı var
(puzzles_database.json). Bu veriyi kullanarak çalışan bir React Native
/ Expo oyun prototipi oluşturmanı istiyorum.

-----------------------------------------------------------------------

ADIM 4 — ANA EKRANLAR
   Şu dört ekranı React Native bileşenleri olarak oluştur:

   A) HomeScreen — Ana sayfa
      - "Faili Meçhul" başlığı
      - Paket listesine git butonu
      - Oyuncu istatistikleri (çözülen vaka sayısı, toplam puan)

   B) PackListScreen — Paket seçimi
      - puzzles_database.json'dan paketleri listele
      - Her paketin ikonu, adı, fiyatı ve zorluk dağılımı görünsün
      - Pakete tıklayınca içindeki 5 bulmacayı göster

   C) PuzzleScreen — Oyun ekranı (EN ÖNEMLİSİ)
      - Üstte: vaka adı, süre sayacı, mevcut puan
      - Ortada: 3 bölüm — Şüpheliler / Silahlar / Mekanlar
        (her birinden birer seçim yapılacak)
      - Altta: İpuçları listesi (sırayla açılır, her birinin puanı var)
      - "Suçla" butonu → seçilen 3 elemanla GameEngine.makeAccusation()
      - Özel mekanikler: ipucu türüne göre ilgili mini oyunu aç

   D) SolutionScreen — Çözüm ekranı
      - Doğru/yanlış sonuç
      - Kazanılan puan
      - Çözüm hikayesi (solutionNarrative)
      - "Sonraki Bulmaca" butonu

ADIM 5 — ÖZEL MEKANİKLER
   Şu 3 mini bileşeni oluştur:

   FingerprintMini.js
   → İpucu türü "parmak_izi" olduğunda açılır
   → Ekranda 3-4 parmak izi kartı göster (farklı şekillerde SVG/emoji)
   → Kullanıcı doğru şüpheliyi seçtiğinde FingerprintGame.match() çağır
   → Doğruysa yeşil, yanlışsa kırmızı animasyon

   CipherMini.js
   → İpucu türü "sifreli_mesaj" olduğunda açılır
   → Şifrelenmiş metni göster
   → Kullanıcı çözüm girer → CipherSolver.attempt() çağır
   → 2. yanlışta ipucu göster, doğruysa çözülmüş metni göster

   WitnessDialog.js
   → İpucu türü "tanik_yuzlesme" olduğunda açılır
   → Soru/cevap sırasıyla göster
   → "Yalan söylüyor mu?" butonu → WitnessDialog.answerQuestion() çağır

-----------------------------------------------------------------------
JSON VERİSİ HAKKINDA BİLMEN GEREKENLER
-----------------------------------------------------------------------

Her bulmacada şu alanlar var:
- puzzleId       : Benzersiz ID (örn: "ott_001")
- difficulty     : 1-5 arası zorluk
- gridSize       : "3x3" veya "4x4"
- suspects[]     : id, name, icon, description
- weapons[]      : id, name, icon, description
- locations[]    : id, name, icon, description
- clues[]        : id, type, revealOrder, pointCost, mechanicType + verisi
- solution       : { suspectId, weaponId, locationId }
- solutionNarrative : Çözüm hikayesi metni

İpucu mekanik türleri:
- "text"          → Sadece metin göster
- "parmak_izi"    → FingerprintMini bileşenini aç, parmakIziVerisi kullan
- "sifreli_mesaj" → CipherMini bileşenini aç, sifre objesi kullan
- "ses_kaydi"     → sesMetni alanını kutuda göster
- "gorsel_ipucu"  → gorselAciklama alanını italik kutu içinde göster
- "tanik_yuzlesme"→ WitnessDialog bileşenini aç, yuzlesmeDialogu kullan
